# kits

what we expect on the bench for **op//002**. exact SKUs and counts can shift —
ask crew on the day what is actually unlocked.

| kit | doc | skill | good for |
|---|---|---|---|
| [Reachy Mini](reachy-mini.md) | this folder | `.cursor/skills/reachy-mini` | expressive head / antennas, vision + speech experiments |
| [SO-ARM101](so-arm101.md) | this folder | `.cursor/skills/so-arm101` | leader–follower teleop, LeRobot learning loops |
| [Arduino + sensors](arduino-sensors.md) | this folder | `.cursor/skills/arduino-sensors` | quick sense → actuate loops, jam prompts |
| [CrowPanel Advance](crowpanel-advance.md) | this folder | `.cursor/skills/crowpanel-advance` | touch UI, ESP32-S3 HMI, on-device display |

## how to choose

- need a face / social robot vibe → Reachy Mini  
- need a manipulator arm → SO-ARM101  
- need “sensor in, LED/motor out” tonight → Arduino + sensors  
- need a touchscreen brain on the desk → CrowPanel Advance  

combine kits if you want. keep one hello-world path green before you glue
systems together.

## shared vs bring-your-own

loaner kits are limited. bring your own Arduino / sensors if you have them.
do not assume exclusive ownership of Reachy / SO-ARM / CrowPanel units.
